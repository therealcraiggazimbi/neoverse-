TROUBLESHOOTING
================================================================================

Q: "undefined reference" during compilation
A: Ensure ALL .cpp files are included in compile command
   Example: g++ -std=c++17 *.cpp -o neoverse_main

Q: Test fails unexpectedly
A: Verify test files haven't been modified
   Run: ./neoverse_tests (show verbose output)

Q: Cannot login
A: Use exact credentials:
   Username: alice_chen
   Password: secure_pass_123
   (Passwords are case-sensitive)

Q: CSV files empty after running
A: First run simulation (Menu 2 → 1)
   Then export data (Menu 3 → 8)

Q: Compilation takes very long
A: Add -O1 or -O2 flag for optimization
   g++ -std=c++17 -O2 *.cpp -o neoverse_main

Q: Clang++ vs G++
A: Both work fine. Script automatically detects available compiler.
